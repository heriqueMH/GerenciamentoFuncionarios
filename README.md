# Java - java-gerenciamento-funcionarios 🧑‍💼

Projeto em Java para gerenciamento de dados de funcionários, com operações básicas de CRUD e separação por camadas.

## ✨ Funcionalidades

- Cadastro de funcionários
- Consulta e listagem de funcionários
- Atualização e exclusão de registros
- Separação entre camadas de dados e lógica de negócio

## 🛠️ Tecnologias Utilizadas

- Java 17
- JDBC ou outro método de persistência simples
- Banco de Dados (PostgreSQL ou H2)

## 🚀 Como executar o projeto

git clone https://github.com/seu-usuario/java-gerenciamento-funcionarios.git
cd java-gerenciamento-funcionarios
